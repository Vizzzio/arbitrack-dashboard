Sourcing Dashboard — Google Maps

One-time setup: get a free Google Maps API key, paste it below, you're done.

1. Create a Google Cloud project

  1. Open console.cloud.google.com/projectcreate and sign in with any Google account.
  2. Name it whatever (e.g. Sourcing) and click Create.

2. Enable Maps APIs

  1. Go to APIs & Services → Library.
  2. Search "Maps JavaScript API" → Enable.
  3. Search "Directions API" → Enable.

3. Create the API key

  1. Go to Credentials → + Create credentials → API key.
  2. Copy the long string starting with AIza….

4. Paste your key

Cost: $200/month free credit from Google = ~28k loads/mo. Personal sourcing typically uses 50–200/mo.

Recommended: in Credentials → click your key → API restrictions, lock to Maps JavaScript API + Directions API only.

Your key is stored only in this browser's localStorage.
